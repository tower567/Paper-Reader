# VLA 与具身智能扩展学习路线：从数据飞轮到可信评测

## 使用方式

这份路线承接 [初学者优先阅读 15 篇](../collections/manual/vla-beginner-priority-15.md)，对应本轮新增的 [28 篇扩展 fast 记录](../collections/manual/vla-extended-fast-28.md)。建议不要逐篇平均用力：先抓住每个模块的一条主线，再用专题论文补证据与反例。

## 一、历史前驱：先弄清“统一”究竟统一了什么

推荐顺序：Gato → CLIPort → BC-Z → CALVIN → VIMA → RoboCat。

- Gato 统一的是可序列化模态、任务和动作，但机器人证据窄、上下文短，新任务通常仍需微调。
- CLIPort 与 BC-Z 展示两种早期语言条件路线：前者强调语义—空间分解，后者强调真实机器人多任务模仿与未见任务组合。
- CALVIN 把短技能扩展为连续语言任务链；VIMA 把语言、目标图像、示范和约束统一成多模态提示。
- RoboCat 把问题推进到多机器人形态、少样本适配和策略自主采集数据，但任务接口仍是视觉目标而非语言。

完成本模块后，应能回答：统一的是输入接口、模型权重、动作空间、任务分布，还是机器人形态？“零样本”是否仍依赖同任务提示、目标图像或训练组件？

## 二、数据工程：VLA 上限往往先由数据系统决定

推荐顺序：BridgeData V2 → DROID → UMI → AutoRT → RoboCasa → AgiBot World Colosseo。

这六篇构成一条从被动数据集到主动数据飞轮的路线：

1. BridgeData V2 说明跨场景真实数据如何组织和用于下游迁移。
2. DROID 把采集扩展到多地点、多操作者和自然环境，强调标准化硬件/软件与数据覆盖。
3. UMI 改变采集接口，让人先在自然场景手持示教，再映射到机器人执行。
4. AutoRT 用 VLM/LLM 为机器人舰队生成和筛选采集任务，混合人类、脚本和自主策略。
5. RoboCasa 用仿真资产与自动轨迹生成扩大日常任务数据，但受 reality gap 约束。
6. AgiBot World 把采集、质量控制、开放数据和通用模型放进工业级平台。

关键判断不只是“轨迹有多少”，还包括：任务/场景覆盖、动作多样性、失败数据、标注粒度、操作者偏差、机器人形态、质量筛选和许可边界。

## 三、动作建模与适配：不要把所有 VLA 都理解成动作 token

推荐顺序：CogACT → RDT-1B → GR00T N1 → RoboVLMs → OpenVLA-OFT → GR-2。

可以用四个维度比较：

| 维度 | 典型选择 | 代表论文 |
|---|---|---|
| 动作表示 | 离散 token、连续回归、cVAE、扩散/flow | OpenVLA-OFT、GR-2、RDT-1B、GR00T N1 |
| 时间结构 | 单步动作、动作块、分层动作 | OpenVLA-OFT、RDT-1B、RT-H |
| 认知—动作耦合 | 单一 decoder、双系统、动作专家 | CogACT、GR00T N1、RoboVLMs |
| 适配方式 | 全量微调、LoRA、冻结骨干＋新动作头 | OpenVLA-OFT、RoboVLMs |

最重要的工程提醒来自 OpenVLA-OFT：动作吞吐量不是闭环观察频率；一个模型可一次生成很多动作，但每个动作块之间是否重新观察和纠错，决定真实控制质量。

## 四、具身推理：中间文本或图像有用，不等于已经证明“会思考”

推荐顺序：RT-H → Embodied CoT → CoT-VLA；GR-2 作为视觉未来预测对照。

- RT-H 把语言动作作为低层控制之上的中间层，使人可以在抽象层纠错并把 intervention 数据并回训练。
- Embodied CoT 监督生成计划、子任务、空间和运动字段，提升泛化、可诊断性和交互纠错。
- CoT-VLA 先生成视觉子目标，再输出动作块，并利用无动作视频监督视觉前瞻。
- GR-2 联合预测未来视频与动作，但没有在部署时搜索多条想象轨迹或用奖励选择，因此不能直接等同在线世界模型规划。

阅读此类论文时依次问：中间表示是否参与动作计算？去掉它是否显著退化？它是否只是可读解释？是否能在失败后更新？是否做反事实搜索？推理延迟是否破坏控制频率？

## 五、评测有效性：从“一个成功率”转向多轴诊断

推荐顺序：THE COLOSSEUM → RoboArena → VLABench → LIBERO-PRO → WorldGym → ManipArena → SafeVLA-Bench。

- THE COLOSSEUM 用系统扰动测试对象、外观、环境和动力学泛化。
- RoboArena 用跨地点真实机器人和成对比较提高策略相对排名的规模与统计效率，但相对偏好不等于绝对成功率。
- VLABench 扩展视觉、语义、世界知识与长时程推理任务，适合诊断“能力类型”，但仍是模拟环境。
- LIBERO-PRO 说明标准 LIBERO 高分可能依赖固定布局和动作序列，结构化扰动会揭示输入不敏感。
- WorldGym 用视频世界模型 rollout 策略并由 VLM 打分，适合作为真机前筛选；接触和 OOD 失真仍会污染排名。
- ManipArena 在统一真实硬件上用 schema、分层 OOD 和部分得分定位失败，代价是任务/模型覆盖有限。
- SafeVLA-Bench 进一步拆开“完成任务”和“安全完成”，用 SBU 与 VSI 暴露成功轨迹中的碰撞、扰物和失稳。

一个更可靠的 VLA 报告至少应同时包含：ID 成功率、结构化 OOD、部分得分或失败阶段、真实机器人结果、延迟/吞吐、语言输入敏感性，以及成功条件下的安全违反率。

## 六、九阶段学习计划

1. Gato、BC-Z：统一序列与真实机器人任务泛化。
2. CALVIN、VIMA、RoboCat：长时程、多模态提示、多形态与数据飞轮。
3. BridgeData V2、DROID、UMI：数据规模、自然环境和低成本示教。
4. AutoRT、RoboCasa、AgiBot World：主动采集、仿真扩增和工业数据平台。
5. CogACT、RDT-1B、GR00T N1、RoboVLMs：主流 VLA 架构与动作头。
6. OpenVLA-OFT、GR-2：高效微调、连续动作块和视频动态先验。
7. RT-H、Embodied CoT、CoT-VLA：语言/视觉中间推理与纠错。
8. COLOSSEUM、RoboArena、VLABench、LIBERO-PRO：泛化与 benchmark validity。
9. WorldGym、ManipArena、SafeVLA-Bench：世界模型预筛、受控真机诊断和安全。

## 七、当前最值得继续追踪的研究问题

1. 跨 embodiment 动作表示：离散 token、连续 flow/diffusion 与统一机器人坐标接口如何兼顾迁移和精度？
2. 数据价值估计：如何让策略失败、任务覆盖、质量和安全风险共同驱动下一轮采集，而非只扩大轨迹数量？
3. 可校准具身推理：中间文本/图像能否支持反事实、失败恢复和不确定性估计，而不只是辅助监督？
4. 世界模型评测：怎样验证策略排序在接触密集、长时程和 OOD 场景中仍与真机一致？
5. 安全与成功共同优化：如何把轨迹级 STL/风险信号用于训练或测试时控制，并完成真实硬件标定？
6. 公平真机比较：怎样跨实验室统一硬件差异、任务 schema、重置随机性、延迟和统计置信区间？

## 证据边界

本路线只使用已在仓库中完成 targeted verification 的论文记录。它用于建立学习结构，不把预印本结果当作最终共识，也不把模拟、视频世界模型或单一真实平台的结论外推到开放世界通用机器人。
